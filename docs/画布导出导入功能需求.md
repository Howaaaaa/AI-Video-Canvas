# 画布导出/导入功能需求文档

## 功能概述

用户可以将当前画布的所有信息和资源打包导出，然后在另一台电脑（安装相同软件）上导入，实现画布的跨设备迁移。

---

## 用户场景

### 场景一：跨设备协作

用户在公司电脑上创建了一个分镜画布，回家后想在个人电脑上继续编辑。

### 场景二：备份存档

用户想将重要的画布项目备份到外部存储设备或云盘。

### 场景三：分享给他人

用户想将画布分享给团队成员，对方导入后可以直接使用。

---

## 导出功能

### 导出内容

| 内容 | 说明 | 是否必须 |
|------|------|---------|
| 项目元数据 | 项目 ID、名称、创建/更新时间 | ✅ 必须 |
| 节点数据 | 所有节点的类型、位置、数据 | ✅ 必须 |
| 边数据 | 节点之间的连接关系 | ✅ 必须 |
| 视口状态 | 画布的位置和缩放比例 | ✅ 必须 |
| 历史记录 | 撤销/重做栈（可选） | ⚪ 可选 |
| 图片文件 | 节点中引用的所有图片 | ✅ 必须 |

### 导出格式

```
project-export.zip
├── manifest.json           # 元数据
├── project.json            # 节点、边、视口、历史记录
└── images/                 # 图片文件
    ├── abc123.png          # 原图（按 MD5 哈希命名）
    ├── abc123_preview.png  # 缩略图
    └── abc123_tiny.png     # 超小缩略图
```

### manifest.json 结构

```json
{
  "version": "1.0",
  "exportTime": "2026-04-28T10:30:00Z",
  "appName": "Storyboard-Copilot",
  "appVersion": "0.1.13",
  "project": {
    "id": "proj-abc123",
    "name": "我的分镜项目",
    "createdAt": 1709234567890,
    "updatedAt": 1709234567890,
    "nodeCount": 25,
    "edgeCount": 12
  },
  "imageCount": 15,
  "totalSize": 52428800
}
```

### 导出流程

```
1. 用户点击"导出画布"按钮
2. 弹出文件保存对话框，选择保存位置和文件名
3. 系统收集项目数据
4. 提取所有图片路径，去重
5. 显示进度条（如有大量图片）
6. 打包成 ZIP 文件
7. 导出完成，显示成功提示
```

### 导出选项（可选）

| 选项 | 说明 | 默认值 |
|------|------|--------|
| 包含历史记录 | 是否包含撤销/重做栈 | 不包含 |
| 只导出缩略图 | 减小文件体积，但放大查看时会模糊 | 否 |
| 压缩级别 | ZIP 压缩程度（速度 vs 体积） | 标准 |

## 导入功能

### 导入流程

```
1. 用户点击"导入画布"按钮
2. 弹出文件选择对话框，选择 ZIP 文件
3. 系统解压到临时目录
4. 读取 manifest.json，验证格式和版本
5. 检查磁盘空间是否足够
6. 复制图片到应用 images 目录
7. 重写节点中的图片路径（路径重映射）
8. 保存项目到数据库
9. 导入完成，打开画布
```

### 路径重映射逻辑

**问题**：导出时图片路径是原电脑的绝对路径，导入后需要映射到新电脑的路径。

**解决方案**：

```typescript
// 导出时：记录图片的相对路径映射
{
  "originalPath": "/Users/yahaoliu/Library/.../images/abc123.png",
  "relativePath": "images/abc123.png",
  "hash": "abc123"
}

// 导入时：根据 hash 找到新路径
const newImagePath = `${appDataDir}/images/${hash}.png`;
// 更新节点数据中的 imageUrl
```

### 导入选项

| 选项 | 说明 | 默认值 |
|------|------|--------|
| 覆盖同名项目 | 如果已存在同名项目，是否覆盖 | 提示用户选择 |
| 重命名导入 | 给导入的项目一个新的名称 | 使用原名称 |

## 错误处理

### 导出错误

| 错误 | 原因 | 处理方式 |
|------|------|---------|
| 图片读取失败 | 图片文件损坏或丢失 | 跳过该图片，记录警告 |
| 空间不足 | 导出目录磁盘空间不足 | 提示用户更换位置 |
| 权限不足 | 无法写入目标目录 | 提示用户更换位置 |

### 导入错误

| 错误 | 原因 | 处理方式 |
|------|------|---------|
| ZIP 文件损坏 | 文件不完整或格式错误 | 提示用户文件无效 |
| 版本不兼容 | 导出版本高于当前应用版本 | 提示用户升级应用 |
| 空间不足 | 应用目录磁盘空间不足 | 提示用户清理空间 |
| 图片导入失败 | 无法复制图片文件 | 节点显示占位符，记录警告 |

## 数据兼容性

### 版本策略

- manifest.json 记录导出时的应用版本
- 导入时检查版本兼容性
- 向后兼容：旧版本导出的文件可以在新版本导入
- 向前不兼容：新版本导出的文件可能无法在旧版本导入（提示升级）

### 数据迁移

如果未来数据结构发生变化：

- 在 manifest.json 中记录数据格式版本
- 导入时根据版本号进行数据迁移
